# SAlert

**Prefer `SAlert` over `UAlert`.** It is the Smartness alert: a compact, color-driven surface with a
built-in slide-in/out transition and an `#actions` slot for any control. Use a bare `UAlert` only when
you need a full-width block, the `actions` prop, or the `ai` / `learning` gradient outlines.

`SAlert` wraps `UAlert` and defaults to `variant="soft"` — the same default as `UBadge` — so inline
alerts read like the rest of the design system. `color` and `variant` drive both the surface and the
text (no forced palette).

## Props

All [`UAlert`](https://ui.nuxt.com/docs/components/alert) props are forwarded (`title`, `description`,
`icon`, `avatar`, `color`, `variant`, `orientation`, `close`, `closeIcon`, `as`, `ui`), plus:

- `show` (`boolean`, default `true`) — toggles the built-in transition by mounting/unmounting the inner `UAlert`.

Defaults differ from `UAlert`: `color="secondary"`, `variant="soft"`, `orientation="horizontal"`.

## Slots

- `#default` — the alert text (mapped to `UAlert`'s title slot).
- `#actions` — the **only** source of actions; place buttons or `SMoreActions` here.

## Events

- `@close` — emitted when the inner `UAlert` close button is dismissed.

## Styling

The baseline `ui` only carries layout, so the color system stays in charge:

- `root`: `rounded-lg shrink-0 px-3 py-2 max-lg:order-last max-lg:w-full lg:w-fit` — compact on
  desktop, full width and pushed last on mobile, which is what a header actions row needs.
- `title`: `font-medium max-w-96 truncate`.

Classes passed via the `ui` prop are **appended per slot** and win on conflicts (tailwind-merge), so
`:ui="{ root: 'w-full' }"` or `:ui="{ title: 'max-w-none' }"` is enough to opt out of a default.

## Quick example

```vue
<SAlert :show="isViewModified" title="You have unsaved changes" icon="ph:info">
	<template #actions>
		<UButton label="Save" size="xs" color="primary" @click="save" />
		<UButton icon="ph:x" size="xs" color="neutral" variant="ghost" @click="isViewModified = false" />
	</template>
</SAlert>

<SAlert color="warning" icon="ph:warning-circle" title="Some presets need a review">
	<template #actions>
		<UButton label="Review" size="sm" @click="reviewAll" />
	</template>
</SAlert>
```

# UAlert — Smartness customizations

`UAlert` registers two compound variants in `app/app.config.ts` that produce gradient-border outlines.

## Extra compound variants

- `color="ai"` + `variant="outline"` → applies `alert-ai-outline ring-0` (root slot).
- `color="learning"` + `variant="outline"` → applies `alert-learning-outline ring-0` (root slot).

## Quick examples

```vue
<UAlert
	color="ai"
	variant="outline"
	title="AI assistance"
	description="Generated by AI based on the trends from the last 30 days."
	icon="ph:sparkle"
/>

<UAlert
	color="learning"
	variant="outline"
	title="Tip"
	description="You can drag rows to reorder them."
	icon="ph:graduation-cap"
/>
```

## Notes

- All other UAlert props (`title`, `description`, `icon`, `actions`, `close`) behave as in Nuxt UI v4.
- Use the gradient outline sparingly — it is meant to mark special, distinctive content (AI suggestions, in-app learning).
